## Steps are snapshots, not deltas

Each stop is a **complete** state, compiled ahead of time.

```rust
let frame = timeline.frame(step)?;
render(frame);
```

Advancing, going back, deep-linking, and printing all index into the same
vector — so they cannot drift apart.
