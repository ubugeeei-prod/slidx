# ステップとアニメーション

スライドは複数の状態を持てます。slidx はそれぞれを **停留** と呼び、停留は差分ではなく
_完全な_ スナップショットです。進む、戻る、`?step=7` へのディープリンク、印刷はすべて
同じベクタへ索引するので、食い違えません。

書いたアニメーションが印刷されるアニメーションである理由です。プロジェクタ、プレゼンター
ビュー、PDF、ソーシャルカードは、同じコンパイル済みタイムラインを消費します。

## 三つの書き方、一つの産物

### 散文の中のマーカー

```md
- Build time fell to 28ms <!-- step -->
- The PDF stopped losing the animation <!-- step -->
```

軽い形で、よくある場合です。箇条書きの末尾のマーカーはその項目を段階付け、行単独の
マーカーは上のブロックを段階付けます。コードフェンス、表、画像の段階の付け方です。

マーカーはプリセットを名指せます。`<!-- step: fly-in -->`。知らない名前は診断になり、
マーカーはそれでも停留になります。トーク前夜の誤字は効果を失うべきで、スライドを失うべきでは
ないからです。

### 自動モード

```md
---
autoSteps: list
---
```

トップレベルの項目を、どこにもマーカーなしで段階付けます。スライドに置くか、デッキの最初の
ブロックに置いて既定にし、丸ごと着いてほしい一枚だけ `autoSteps: none` にします。

### 明示したリスト

```md
---
steps:
  - reveal: ".finding"
  - emphasize: { target: "#result", preset: pulse }
  - set: { target: "#latency", color: success }
  - group:
      - reveal: ".left"
      - reveal: ".right"
---
```

動詞は五つ。`reveal` は要素を出し、`hide` は外し、`emphasize` は既にあるものへ注意を引き、
`set` は要素をその場で変え、`group` は複数の意図を一クリックに載せます。`emphasise` も
受け付けます。一つの語の二つの綴りで厳しくする話ではないからです。

それぞれ `preset:`、ミリ秒の `duration:`、待たずに自分で再生する停留のためのミリ秒の
`after:`、移動するプリセットのための `from:` を取ります。

## プリセット

**phase** 列は、プリセットが属するときを言います。入場、強調、退場。コストは飾りでは
ありません。`motion` 規則は、効果がコンポジタに留まらないスライドに印を付け、発火するかを
決めるのがこの列です。

## Addressing part of a line

_マーク_ はブロックの中の範囲に名前を付けます。ビジュアルエディタが指せるいちばん小さい
もので、三語を選んで色を付けたときにファイルの行き場がある理由です。

```md
The result was [3.2x faster]{#result .accent}.
```

## すでに画面にあるものを変える

reveal は「まだない」をカバーします。_変わる_ 値は、テイクを隣に並べて書くと、連続する
状態を持つ一つの要素になります。

```md
Latency dropped to [120ms]{#latency}[38ms]{#latency}.
```

入れ替わる二つではなく、テキストが変わる一つの DOM ノードです。戻ると前の値が出ます。
各停留は完全なスナップショットで、ランタイムは履歴を持たないからです。

内容ではなくプロパティなら、タイムラインで `set:` と言います。

## マーカーが残すもの

マーカーはどれも、Markdown の中の空の `<span data-slidx-step="N" hidden>` にコンパイル
されます。どの Markdown レンダラでも残るので、slidx はフレームワーク非依存です。Vue の
island、React の island、素のスライドはどれも同じ場所に同じアンカーを持ち、ランタイムは
クライアントと印刷レンダラで同じ一つの規則で、段階付けられた要素をそこから解決します。

[モジュール自身の文書](../../../crates/slidx_core/src/markers.rs) がその規則を三つの
場合で述べ、レンダラがそれぞれを断言します。
